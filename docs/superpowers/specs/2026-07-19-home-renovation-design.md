# ホーム改装設計「経験は、検索できる。」（2026-07-19）

Xカード（深緑OGP・5f891ea）を見てタップした人が、同じ世界観のまま着地し、
迷わずアプリまで流れる一本道を作る。オーナー承認済みの設計。

## 決定事項

1. **ヒーロー刷新**：OGPと同じ常盤グリーングラデ（#175c44→#124a36→#0e3a2b）＋クリームドット柄＋ミントの光。
   H1は白「経験は、検索できる。」、「検索」はアンバー #ffc95c＋太アンダーライン（OGPと同一処理）。
   CTAはアンバーの「今すぐ体験する（無料）」＋半透明ゴーストの「自分のNotionをつなぐ」。
   スマホ実機デモ（自動タイピング検索）は維持し、白リング＋濃い影で浮かせる。
   信頼チップはOGP同様の半透明チップ（高速検索／一問一答クイズ／いつものNotionにつなぐだけ）。
   注意：`.hero{color:クリーム}` がモック内部に継承されるため `.mock-screen{color:var(--ink)}` で遮断。

2. **「30秒ではじめる」帯を新設**（ヒーロー直下 `#quickstart`）：
   ①アプリを開く→②メールで6桁コード→③検索してみる の3ステップ＋CTA。
   既存 `.setup-teaser`／`.st-flow` 系のスタイルを流用した `.quickstart` カード。

3. **セクション再配置**：無料テンプレbannerをヒーロー直下から「はじめかたは2つ」(#start)の直後へ移動
   （Notionつなぐ派の入口として。アプリ導線との競合を解消）。

4. **モバイル追従CTA**：`#stickyCta`。ヒーロー通過後に表示・最終CTA帯(#finalCta)が見えたら非表示。
   IntersectionObserver は参照GCで沈黙する事例があったため、素の scroll リスナー＋
   getBoundingClientRect 判定（rAFスロットリングなし。プレビュー環境でrAF凍結もあったため）。

5. **コピー同期**：title／meta description／最終CTA帯見出し／フッタータグラインを新コピー系に統一。
   ヒーロー以外の本文トーンは既存の静かな日本語を維持（宣伝語・AI主役はNG）。
