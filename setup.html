🚀 はじめての方へ

さあ、はじめてみましょう。

「Notionって何？」「トークンって何？」というところから、一つずつ解説します。順番どおりに進めれば、初めての方でも迷わず設定できます。

Before you start

はじめに：3つの言葉だけ覚えればOK

設定で出てくる言葉は、ほぼこの3つだけ。ここを押さえれば、あとは流れに沿うだけです。

これは何？

Notion（ノーション）

メモ・表・データベースを作れる無料の万能ノートアプリ。MediNodeは「あなたがNotionに書いた医療メモ」を読みに行って検索します。お持ちでなければ無料登録から。

これは何？

データベース（DB）

Notionの中の「表形式のページ集」のこと。1行＝1つの知識。MediNodeは配布テンプレを複製するだけで、必要な形のDBが手に入ります。

これは何？

コネクトToken（トークン）

MediNodeがあなたのNotionを読むための「合鍵」。ntn_ で始まる文字列です。Notionの設定ページで無料で発行でき、あなたのブラウザにだけ保存されます。

🔒
入力したトークンやキーはあなたの端末（ブラウザ）にだけ保存され、サーバーには送られません。DBを「Web公開」する必要もありません（非公開のまま読めます）。

🧑 自分の知識を使うルート

自分のNotionに作った医療メモを検索・クイズ化します。手順は「モード選択 → Notion設定 →（必要なら）オプション」。最短ならNotionを繋ぐだけです。

1

「自分の知識を使う」を選ぶ 必須

最初の画面で「🧑 自分の知識を使う」にチェックして「次へ」。これでこのルートに進みます。

2

接続モードを選ぶ 必須

検索の速さと手軽さのどちらを取るかを選びます。あとから設定でいつでも変更できます。

📋 シンプルモード まず試す方へ

Algoliaアカウント不要、設定はNotion Tokenのみ。最短ですぐ始められます。

※ 検索のたびNotionへ問い合わせるため、表示まで1〜3秒かかります。

⚡ パワーモード 本格利用に

Algoliaで0.1秒以下の高速検索。日本語の部分一致やジャンル絞り込みも快適。

※ Algoliaの無料アカウントが必要。記事を更新するたび再同期します。

Algolia（アルゴリア）って何？
超高速な検索エンジンのサービスです。無料プラン（Build）があり、これを使うと検索が一瞬になります。必須ではありません——まずはシンプルモードで試し、物足りなくなってからで大丈夫です。
3

使うDBを用意する 必須

ここがメインです。まず「どのDBを検索対象にするか」を決めます。2通りから選べます。

📋 ① テンプレートを複製して使う おすすめ・初めての方

アプリ内のリンクから配布テンプレ（Medical／Reference／📋Manual の3DB入り）を自分のNotionへ複製するだけ。必須プロパティが最初から揃っているので、手間なく始められます。

🔗 ② 既存のDBに連携する すでにNotionで運用中の方

すでに医療メモのDBをNotionで使っているなら、複製せずそのDBのURLを貼って接続できます。その際は必須プロパティ名（名前・ジャンル・知識レベル・要約・キーワード）を正確に合わせておきます。選択肢の値（ジャンル名など）は自由でOKです。

データベース（DB）って何？どっちを選べばいい？
DBは「表形式のページ集」のこと（1行＝1つの知識）。初めての方は①テンプレ複製が確実です。すでにNotionで症例メモや勉強ノートをDBで管理している方は、②で今のDBをそのまま活かせます。後から追加・変更もできます。
4

合鍵（コネクトToken）を作って接続する 必須

MediNodeがあなたのDBを読めるように、合鍵を発行して、DBにつなぎます。

  1. コネクトTokenを取得：notion.so/my-integrations →「新しいインテグレーション」を作成 →「シークレット（アクセストークン）」の ntn_ から始まる文字列をコピー。
  2. DBに合鍵を接続：使うDBページを開き、右上「…」→「コネクトを追加」→ 作ったコネクトを選択。Medical DB・Reference DB の両方に行います。
  3. アプリに入力：セットアップ画面でコネクトTokenと各DBのURLを貼り付けて保存。
インテグレーション／コネクトって何？（トークンとの関係）
「インテグレーション（旧称）」＝「コネクト（新称）」で、外部アプリにNotionを読ませる許可の単位です。これを作ると合鍵（ntn_ トークン）が発行されます。さらに「どのDBを読ませるか」を、各DBの「…→コネクトを追加」で個別に許可します。この接続を忘れると同期時に「403エラー」になります。
⚠️
トークンは ntn_（新）または secret_（旧）で始まります。パスワードと同じく他人に教えないでください。
+

Algolia設定＆同期 パワーモードのみ

シンプルモードならこの手順は表示されません。パワーモードを選んだ時だけ必要です。

  • Algolia で無料アカウント（Buildプラン）を作成
  • ダッシュボード →「Settings → API Keys」で3つをコピー：App ID ／ Search-Only API Key（検索用）／ Admin API Key（同期用）
  • キーを入力後、「🔄 データを再同期する」で同期。Notionを更新したら毎回再同期します。
⚠️
「Admin API Key」と「Search-Only Key」を取り違えないように。Admin Keyは秘密にしてください。
+

オプション設定 任意

ほとんどの方はスキップでOK。あとから設定画面（⚙️）で変更できます。部署DB・プレミアム・📋マニュアルDBを後から足すのもここからです。

📋マニュアルタブって何？（病院・部署向け）
病院・部署のマニュアル／お知らせ／業務改善を検索・新着表示できる任意のタブです。Manual DBを設定すると表示されます（設定した人だけに出るオプトイン方式）。新着順はNotionの最終更新日時を使うので改訂すると自動で上に来ます。Notion直読みのためパワーモードでも再同期は不要です。
✓

完了！検索してみる

「設定を保存して検索を開始」を押せば完了。シンプルモードなら、Notionを直すと次の検索から即反映されます。お疲れさまでした。

🏢 みんなの知識を使うルート

職場・チームで共有しているDBを検索します。自分のNotionは不要。代表者から「トークン」と「DBのURL」をもらって貼るだけ。モード選択もスキップされ、すぐ使えます。

1

「みんなの知識を使う」を選ぶ 必須

最初の画面で「🏢 みんなの知識を使う」にチェック。部署のみを選んだ場合、Algoliaなどの設定はスキップされます。

2

代表者から2つをもらう 必須

チームでDBを管理している代表者（先輩・管理担当）に、次の2つを聞きます。

  • 共有用のコネクトToken（ntn_ で始まる文字列）
  • 共有DBのURL（部署のMedical DB／Reference DBのリンク）
看護師など「ゲスト」でも使える？
はい。MediNodeはNotion公式AIのコネクトではなく、利用者自身（または代表者）が作る内部コネクト（ntn_ トークン）でDBに接続します。対象DBに「コネクトを追加」されていれば、メンバー・ゲストの区別なくアプリ内で閲覧できます。
3

アプリに貼り付ける 必須

もらったトークンとDBのURLを、セットアップ画面（または設定→部署DB）に貼り付けて保存。これだけで部署の知識を検索できます。

💡
検索バー下の「部署」フィルタでチームの知識に絞り込めます。自分の知識（個人）と一緒に横断検索も可能です。
✓

完了！

自分でNotionを用意しなくても、チームの知識をすぐ引けます。後から「自分の知識」を足したくなったら、設定からいつでも追加できます。

⭐ 専門医の知識を使うルート

作者（専門医）がメンテナンスする医療ナレッジ・参考文献を検索します。自分のNotionもAlgoliaも不要。登録すればすぐ使えます。シンプルモードのままでも利用できます。

1

「専門医の知識を使う」を選ぶ 必須

最初の画面で「⭐ 専門医の知識を使う」にチェック。Notion/Algoliaの設定はスキップされます。

2

プレミアムに登録 必須

各タブの「⭐プレミアム」フィルタ、または設定パネルの登録ボタンから手続きします。決済はStripeの画面で行います（価格は登録画面に表示）。

支払いは安全？端末をまたいで使える？
カード情報は決済代行のStripeが管理し、アプリは保持しません。また「ログイン」（メールアドレスのみ・パスワード不要）すれば、プレミアム契約をスマホ・PCなど複数端末で引き継げます。ログインは任意で、基本機能はログインなしでも使えます。
ℹ️
お申し込み・お支払いはアプリ内で行います。このサイトでは手続きできません。
✓

完了！

登録後すぐ、⭐プレミアムフィルタで作者のキュレーション知識を検索できます。自分・部署の知識と並べて横断検索も可能です。

Tips

つまずきやすいポイント

📱
スマホのホーム画面に追加（PWA）するなら：SafariとPWAは保存場所が別です。先にホーム画面へ追加してから、PWAを開いて設定してください。Safariで設定してもPWAには引き継がれません。
🔄
追加した知識が出てこない：パワーモードでは、Notionを更新したら「🔄 データを再同期する」が必要です。シンプルモードは即反映で同期不要です。
🚫
同期で「403エラー」：DBへの「コネクトを追加」が漏れています。各DBの「…→コネクトを追加」を確認してください。
🔐
Web公開は不要：アプリ内の閲覧はトークン＋API経由なので、DBは非公開のままでOK。医療情報を扱うため、Web公開はオフのままを推奨します。
