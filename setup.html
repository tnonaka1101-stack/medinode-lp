Before you start

はじめに：3つの言葉だけ覚えればOK

設定で出てくる言葉は、ほぼこの3つだけ。ここを押さえれば、あとは流れに沿うだけです。

これは何？

Notion（ノーション）

メモ・表・データベースを作れる、無料のノートアプリ。MediNodeは、あなたがNotionに書いた医療メモを読みに行って検索します。お持ちでなければNotion公式から無料登録できます。使い方はNotion入門（note）で。

書いた分だけ増えていく、あなたの本棚。

これは何？

データベース（DB）

Notionの中の「表形式のページ」のこと。1行が1つの知識。配布テンプレを複製すれば、必要な形のDBがそのまま手に入ります。

その本棚の、ひと棚。テンプレを複製すれば、棚ごと手に入ります。

これは何？

コネクトToken（トークン）

MediNodeがあなたのNotionを読むための鍵。ntn_ で始まる文字列で、Notionの設定ページから無料で発行できます。入力後は暗号化して保存されます。

棚を開ける鍵。つくって、渡すだけです。

💡
この3つは、すべて無料です。「Algolia」という言葉ももう一つ出てきますが、検索をさらに速くしたい人向けの任意のもの。使わなくても、すべての機能が動きます。
🔒
入力したトークンやキーは、ログイン後に暗号化したうえで保存され、スマホ・PCなど別の端末でも同じ設定で使えます。DBを「Web公開」する必要はありません（非公開のまま読めます）。

自分のNotionに作った医療メモを検索・クイズ化します。手順は「モード選択 → Notion設定 →（必要なら）オプション」。最短ならNotionを繋ぐだけです。

1

「自分の知識を使う」を選ぶ 必須

最初の画面で「🧑 自分の知識を使う」にチェックして「次へ」。これでこのルートに進みます。

2

接続モードを選ぶ 必須

検索の速さと手軽さのどちらを取るかを選びます。あとから設定でいつでも変更できます。

📋 シンプルモード まず試す方へ

Algoliaアカウント不要、設定はNotion Tokenのみ。最短ですぐ始められます。

※ 検索のたびNotionへ問い合わせるため、表示まで1〜3秒かかります。

⚡ パワーモード 本格利用に

Algoliaでさらに速い検索に。日本語の部分一致やジャンル絞り込みも快適。

※ Algoliaの無料アカウントが必要。記事を更新するたび再同期します。

Algolia（アルゴリア）って何？
超高速な検索エンジンのサービスです。無料プラン（Build）があり、これを使うと検索が一瞬になります。必須ではありません——まずはシンプルモードで試し、物足りなくなってからで大丈夫です。
3

使うDBを用意する 必須

ここがメインです。まず「どのDBを検索対象にするか」を決めます。2通りから選べます。

📋 ① テンプレートを複製して使う おすすめ・初めての方

配布テンプレ（Medical／Reference／📋Manual の3DB入り）を自分のNotionへ複製するだけ。必須プロパティが最初から揃っているので、手間なく始められます。

🎁 無料テンプレを入手（Notionマーケットプレイス）→
🔗 ② 既存のDBに連携する すでにNotionで運用中の方

すでに医療メモのDBをNotionで使っているなら、複製せずそのDBのURLを貼って接続できます。その際は必須プロパティ名（名前・ジャンル・知識レベル・要約・キーワード）を正確に合わせておきます。選択肢の値（ジャンル名など）は自由でOKです。

🧭 Notion側の準備だけを図解で見る →
データベース（DB）って何？どっちを選べばいい？
DBは「表形式のページ集」のこと（1行＝1つの知識）。初めての方は①テンプレ複製が確実です。すでにNotionで症例メモや勉強ノートをDBで管理している方は、②で今のDBをそのまま活かせます。後から追加・変更もできます。
4

コネクト（鍵）を作って、DBに接続する 必須

Notion側での準備は、実際の画面で。下の順番どおりに進めれば大丈夫です。

💻
画像はPC画面です。初回設定はパソコンのブラウザで行うのがおすすめ。設定の最後にアカウント登録すると保存されるので、スマホではアプリを開いてログインするだけで引き継げます。スマホだけでも設定はでき、その場合もボタンの名前は同じです（アプリ内の画面つきガイドに「スマホで設定中」表示があります）。

「コネクト」ページを開く。notion.so/my-integrations を開き（要ログイン）、右上の「＋新規コネクト」をクリック。
※ スマホでリンクからNotionアプリが開いてしまう場合は、SafariやChromeのアドレス欄に notion.so/my-integrations を直接入力して開いてください（Notionアプリにはこの作成画面がありません）。

名前を付けて作成。名前は自分がわかればOK。認証方法は「アクセストークン」を選んで「コネクトを作成」。

アクセストークン（＝鍵）をコピー。作成後の画面に表示されます。機能はそのままでOK。ntn_ で始まる文字列です。

使うDBをフルページで開き、右上の「…」をクリック。Medical・Referenceの各DBで、同じ操作を繰り返します。

メニューの「接続」→「接続を追加」を選びます。

さきほど作った「MediNode」を探してクリック。

「ページに追加」で接続完了。あとは、コピーしたトークンと各DBのURLを、アプリのセットアップ画面に貼り付けて保存するだけです。

「インテグレーション」と「コネクト」って違うもの？
同じものです。Notionが名前を変えている途中で、「インテグレーション（旧称）」＝「コネクト（新称）」。どちらも外部アプリにNotionを読ませる許可のことです。これを作ると合鍵（ntn_ トークン）ができ、さらに「どのDBを読ませるか」を各DBの「…→コネクトを追加」で1つずつ許可します。
⚠️
トークンは ntn_（新）または secret_（旧）で始まります。パスワードと同じく他人に教えないでください。
「②の接続」を忘れると、同期のときに「403エラー」と出ます。各DBの「…→コネクトを追加」を見直せば直ります。
+

Algolia設定＆同期 パワーモードのみ

シンプルモードなら、この手順は表示されません。パワーモードを選んだときだけ必要です。やることは、無料登録して3つのキーをコピーし、貼り付けて再同期するだけです。

Algolia で無料登録（Buildプラン）。登録するとアプリが自動で用意されます。ダッシュボード上部の「API Keys」を開きます。

3つの値をコピーして、アプリの設定画面に貼り付けます（下でどれがどれか説明します）。

1
Application ID 公開OK

アプリの識別番号。名前のようなもので、人に見られても問題ありません。

2
Search API Key 公開OK・検索用

「検索するだけ」の鍵。読み取り専用なので安全です。

3
Admin API Key 秘密・同期用

データを書き換えられる強力な鍵。絶対に他人に渡さないでください。同期のときに使います。

⚠️
③Admin Key の欄に ②Search API Key を入れる取り違えに注意。同期に使う鍵は「Admin」です。取り違えると「App IDまたはAdmin API Keyが正しくありません」と表示されます。
📦
インデックスは、初回の「再同期」で自動的に作られます。Algolia側で新しく作る必要はありません。3つのキーを貼り付けて「🔄 データを再同期する」を押せば、Notionの知識が送られて検索の準備が整います。
🔄
その後Notionに知識を書き足したら、「🔄 データを再同期する」を押すと反映されます（パワーモードの特徴）。すぐ反映したい人はシンプルモードが向いています。
+

オプション設定 任意

ほとんどの方はスキップでOK。あとから設定画面（⚙️）で変更できます。部署DB・プレミアム・📋マニュアルDBを後から足すのもここからです。

📋マニュアルタブって何？（病院・部署向け）
病院・部署のマニュアル／お知らせ／業務改善を検索・新着表示できる任意のタブです。Manual DBを設定すると表示されます（設定した人だけに出るオプトイン方式）。新着順はNotionの最終更新日時を使うので改訂すると自動で上に来ます。Notion直読みのためパワーモードでも再同期は不要です。
✓

完了！検索してみる

「設定を保存して検索を開始」を押せば完了。シンプルモードなら、Notionを直すと次の検索から即反映されます。お疲れさまでした。

🏥 みんなの知識を使うルート

職場・チームで共有しているDBを検索します。自分のNotionは不要。代表者から「トークン」と「DBのURL」をもらって貼るだけ。モード選択もスキップされ、すぐ使えます。

1

「みんなの知識を使う」を選ぶ 必須

最初の画面で「🏥 みんなの知識を使う」にチェック。部署のみを選んだ場合、Algoliaなどの設定はスキップされます。

2

代表者から2つをもらう 必須

チームでDBを管理している代表者（先輩・管理担当）に、次の2つを聞きます。

  • 共有用のコネクトToken（ntn_ で始まる文字列）
  • 共有DBのURL（部署のMedical DB／Reference DBのリンク）
看護師など「ゲスト」でも使える？
はい。MediNodeはNotion公式AIのコネクトではなく、利用者自身（または代表者）が作る内部コネクト（ntn_ トークン）でDBに接続します。対象DBに「コネクトを追加」されていれば、メンバー・ゲストの区別なくアプリ内で閲覧できます。
3

アプリに貼り付ける 必須

もらったトークンとDBのURLを、セットアップ画面（または設定→部署DB）に貼り付けて保存。これだけで部署の知識を検索できます。

💡
検索バー下の「部署」フィルタでチームの知識に絞り込めます。自分の知識（個人）と一緒に横断検索も可能です。
✓

完了！

自分でNotionを用意しなくても、チームの知識をすぐ引けます。後から「自分の知識」を足したくなったら、設定からいつでも追加できます。

⭐ 専門医の知識を使うルート

作者（専門医）がメンテナンスする医療ナレッジ・参考文献を検索します。自分のNotionもAlgoliaも不要。登録すればすぐ使えます。シンプルモードのままでも利用できます。

1

「専門医の知識を使う」を選ぶ 必須

最初の画面で「⭐ 専門医の知識を使う」にチェック。Notion/Algoliaの設定はスキップされます。

2

まずは無料で試す 必須

各タブの「⭐プレミアム」フィルタ、または設定パネルの登録ボタンから進みます。始め方は2通りです。

🎁 ① noteの無料コードを入力 カード不要・2週間

note記事に載っている無料コードをアプリの登録画面に入力すると、カード登録なしで14日間試せます。期間が終わると自動で通常表示に戻り、勝手に課金されることはありません。

💳 ② カード登録で始める 最初の1週間無料

カードを登録すると、最初の1週間は無料。以降は月額980円（税込）で、いつでも解約できます。決済はStripeが管理し、アプリはカード情報を保持しません。

端末をまたいで使える？
メールアドレスでログインすれば、プレミアムをスマホ・PCなど複数端末で引き継げます。ご利用にはログインが必要で、トップの閲覧と初回のセットアップだけ登録前から進められます。ログインはパスワード不要（メールのリンクまたは確認コードで認証）です。
ℹ️
お申し込み・コードの入力・お支払いは、すべてアプリ内で行います。このサイトでは手続きできません。無料コードはDr.ノードのnoteで配布しています。
✓

完了！

登録後すぐ、⭐プレミアムフィルタで作者のキュレーション知識を検索できます。自分・部署の知識と並べて横断検索も可能です。

Tips

つまずきやすいポイント

📱
スマホのホーム画面に追加（PWA）するなら：SafariとPWAは保存場所が別です。先にホーム画面へ追加してから、PWAを開いて設定してください。Safariで設定してもPWAには引き継がれません。
🔄
追加した知識が出てこない：パワーモードでは、Notionを更新したら「🔄 データを再同期する」が必要です。シンプルモードは即反映で同期不要です。
🚫
同期で「403エラー」：DBへの「コネクトを追加」が漏れています。各DBの「…→コネクトを追加」を確認してください。
🔑
トークン作成ページでNotionアプリが開いてしまう：Notionアプリにはコネクトの作成画面がないため、そこから先へ進めません。SafariやChromeのアドレス欄に notion.so/my-integrations を直接入力して、ブラウザで開いてください。ブラウザならスマホでも作成できます。
🔐
Web公開は不要：アプリ内の閲覧はトークン＋API経由なので、DBは非公開のままでOK。医療情報を扱うため、Web公開はオフのままを推奨します。
